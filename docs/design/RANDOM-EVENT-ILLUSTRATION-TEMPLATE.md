# 《Surviving LA》随机事件插图模板

本文件定义游戏中所有随机事件插图的统一制作要求。新增事件时，复制文末的“事件插图需求单”和“ImageGen 提示词模板”，替换方括号内容即可。

## 1. 交付规格

- 画布：`1536 × 1024 px`，横向 `3:2`。
- 格式：PNG，sRGB，不使用透明背景。
- 游戏资产命名：`Event_<EventID>`，例如 `Event_TempJobOffer`。
- 原始文件命名：`event_<event-id>_1536x1024.png`，只使用小写英文、数字和连字符。
- 每个事件只交付一张主图；除非剧情明确需要，不制作分镜、拼贴或多格漫画。

## 2. 固定美术方向

- 风格：成熟、克制的印象派叙事油画；可见笔触、颜料堆叠与空气感，避免照片般锐利。
- 气质：现实主义底色，略带黑色幽默与命运感；不做廉价励志海报，也不把困境浪漫化。
- 主色：午夜海军蓝、炭黑、烟灰蓝、低饱和青绿色。
- 强调色：珊瑚红、落日橙、钨丝灯琥珀色；强调色只用于视线焦点。
- 光线：环境光主导，可使用晨昏、霓虹、路灯、车灯或室内暖光形成冷暖对比。
- 人物：普通成年移民/劳动者的真实体态与衣着，不使用明星脸，不美化成英雄海报。

## 3. 构图与安全区

- 一张图只讲一个决定性瞬间：一个主角、一个主要动作、一个清晰情绪。
- 主体放在画面中部或中上部，距离四边至少保留约 `8%–10%` 的裁切余量。
- 面部、手部和关键道具不得贴边，必须能承受 SwiftUI 的 `scaledToFill()` 裁切。
- 下方 `28%–35%` 保持相对安静、偏暗、低细节，供标题、正文或渐变遮罩使用。
- 画面上半部承担环境叙事；背景最多保留 2–3 个能解释事件的线索，避免元素堆叠。
- 默认适配竖屏弹窗中的横向主图区域；在 `366 × 226 pt` 左右的视窗中仍应一眼看清主体。

## 4. 不允许出现

- 任何可读文字、字母、数字、字幕、Logo、水印、品牌标识或仿 UI 元素。
- 写实摄影、电影剧照感、动漫、卡通、3D 渲染、矢量扁平插画。
- 过度饱和、纯黑死暗、廉价红色警报效果或满画面火花粒子。
- 血腥、猎奇、羞辱性刻画，或对移民、贫困、疾病和执法冲突的戏谑化表现。
- 多余肢体、畸形手指、扭曲五官、漂浮物体、透视错误和无法解释的光源。

## 5. 不同事件类型的色彩倾向

| 类型 | 视觉倾向 | 强调色 | 情绪关键词 |
| --- | --- | --- | --- |
| Opportunity | 暗部中出现明确暖光出口 | 琥珀、珊瑚橙 | 机会、诱惑、微弱希望 |
| Setback | 冷暗环境压过人物，保留一个危险焦点 | 暗红、冷蓝 | 压力、意外、失控 |
| Health | 空间更安静，降低饱和度与对比 | 灰绿、医院冷白 | 疲惫、疼痛、脆弱 |
| Reputation | 人群视线、手机光或社交场景形成压力 | 紫红、珊瑚红 | 尴尬、评价、曝光 |

色彩倾向仅用于建立系列一致性，不能取代具体剧情。

## 7. ImageGen 提示词模板

```text
为 iOS 叙事生存游戏《Surviving LA》创作一张随机事件插图。

场景：在[时间与天气]的[发生地点]，[主角状态]的中国中年男性正在[决定性瞬间]。画面中只保留这些叙事线索：[环境线索，最多三个]。核心情绪是[主情绪]，同时带有[副情绪]；视觉焦点是[视觉焦点]。

采用成熟克制的印象派叙事油画风格，明显但自然的油画笔触与颜料堆叠，现实主义人物比例，富有空气感。整体使用午夜海军蓝、炭黑、烟灰蓝和低饱和青绿色，以[事件类型对应强调色]形成小面积冷暖对比。氛围真实、略带命运感，不浪漫化困境。

横向 3:2 构图，1536×1024。主角位于中部或中上部，四周保留 8%–10% 裁切余量；面部、手部和关键道具不能贴边。画面下方约 30% 保持深色、低细节、安静，方便原生 UI 叠加标题和正文。必须出现：[必须出现]。禁止出现：[禁止出现]。

画面中不要生成任何文字、字母、数字、字幕、Logo、水印、品牌、国旗或 UI。不要照片写实、动漫、卡通、3D 渲染、分镜拼贴、血腥猎奇、夸张英雄姿势、畸形肢体或多余手指。
```

## 8. SwiftUI 接入约定

```swift
Image("Event_<EventID>")
    .resizable()
    .scaledToFill()
    .frame(maxWidth: .infinity)
    .frame(height: 226)
    .clipped()
    .accessibilityLabel("[用一句话描述事件画面]")
```

- 图片只负责氛围和叙事，标题与正文使用原生 SwiftUI 文本，避免把文字烘焙进图片。
- 小屏适配时优先裁切环境边缘，不裁切脸、手和关键道具。
- 如果弹窗采用图文上下排版，可保留下方暗区但不强制叠字；这样同一资产可复用于卡片和全屏故事页。

## 9. 出图验收清单

- [ ] 尺寸为 1536×1024，PNG，3:2。
- [ ] 一眼能识别事件的主要人物、动作与情绪。
- [ ] 具有统一的印象派油画笔触，不像照片、动漫或 3D。
- [ ] 主体和关键道具在安全区内，竖屏弹窗裁切后仍完整。
- [ ] 下方约 30% 足够安静，可叠加原生文字。
- [ ] 配色符合事件类型，并与游戏的深蓝/炭黑/珊瑚色体系一致。
- [ ] 没有文字、Logo、水印、畸形手部、多余肢体或异常透视。
- [ ] 敏感题材表达克制、尊重，不猎奇、不嘲讽、不美化困境。
- [ ] 在目标 iPhone 尺寸上实机或预览检查过 `scaledToFill()` 裁切。
- [ ] 已设置准确、简短的无障碍描述。

## 10. 模板入口

在 Codex 中添加 `@Product Design` 后，从 Template Gallery 选择 **Surviving LA · 随机事件油画**；也可以在提示中直接标记 `$artifact-template-survive-in-la`，再附上第 6 节的事件需求单。
