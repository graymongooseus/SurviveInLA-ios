# App Icon Concepts

Three visual directions generated from the current game UI:

- `option-1-city-beacon.png` — sunset + map pin; emphasizes Los Angeles and navigation.
- `option-2-market-skyline.png` — market chart + city silhouette; emphasizes trading and opportunity.
- `option-3-forty-day-hourglass.png` — hourglass + city grid; emphasizes the limited-life-run structure.
- `option-3b-hidden-la-iceberg.png` — skyline above the waterline and the city's hidden survival reality below.
- `option-3c-light-collage.png` — lighter cut-paper/comic-poster interpretation of the hidden-LA iceberg concept.
- `option-3d-immigrant-workers-collage.png` — immigrant workers in trucking, cleaning, delivery, and street-food barbecue supporting the city above.
- `option-3e-immigrant-workers-car-delivery.png` — replaces bicycle delivery with a generic Japanese compact hybrid used for LA food delivery.

These are concept masters. The selected direction should receive a final small-size legibility pass before being installed in `AppIcon.appiconset`.
