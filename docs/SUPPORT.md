# 《洛杉矶浮生记》用户支持

如果遇到闪退、存档异常、界面错位或游戏规则问题，请在 [GitHub Issues](https://github.com/graymongooseus/SurviveInLA-ios/issues) 提交反馈。

反馈时建议包含：

- iPhone 型号和 iOS 版本。
- App 版本号与 Build 号。
- 可复现问题的操作步骤。
- 不含个人隐私信息的截图。

本 App 不需要开发者账号或订阅。奇遇商店包含可选的消耗型 App 内购买；付款和交易由 Apple 处理。删除 App 会删除设备上的本地游戏存档，但用户此前主动同步到 iCloud 的存档可能在重新安装并开启同步后恢复。
