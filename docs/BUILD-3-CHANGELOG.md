# Surviving LA 1.1 · Build 3

发布日期：2026-09-07。

此提交同步当前真机版本的完整 iOS 源码、配套资源、单元测试和内容校验脚本。版本号保持 `1.1`，Debug 与 Release 的构建号从 `2` 调整为 `3`。

## 本次界面与服务更新

- 社区诊所每个游戏周有 70% 概率休诊，从 11 个美国联邦假日中随机选取休诊理由。同一周的结果不会因页面重开或读档而变化。
- 营业周累计最多治疗 30 点健康，按实际恢复点数收取每点 $25，不能通过分次治疗突破额度。
- 新增波霸按摩院，每个游戏周可使用一次，每次 $600，最多恢复 10 点健康。健康不足 10 点时仍收取整次费用，界面会提前提示。
- 游戏设置底部显示反馈邮箱 `liu@graymongoose.us`，点击打开邮件应用；版本信息自动读取安装包。

## 同步的现有手机版本功能

- 52 周生存、运气、住宅和车辆配置、美国生存路线、状态变化记录与多个每周行动。
- JSON 事件库、条件与权重抽取、世界事件持续效果、人生选择和 FF 投资事件。
- 事件插图、世界排名客户端、存档兼容与旅程结算。
- 保留远端已有的隐私清单及其打包配置。

事件库配置见 [事件内容开发指南](EVENT-CONTENT-AUTHORING.md)。
