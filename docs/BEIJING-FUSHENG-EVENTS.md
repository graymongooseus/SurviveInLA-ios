# 《北京浮生记》v1.2.2 事件全表

## 1. 统计口径

本表按当前仓库中的原版 C++ 源码整理。

- **硬编码随机事件共 37 条**：18 条市场事件、12 条健康事件、7 条钱财事件。
- **可选随机规则 1 条**：在设置中开启“黑客活动”后，存款可能随机增减。
- 此外还有强制住院、债务危机、倒计时、声望、设施互动和结局等**规则型事件**。
- `News.txt` / `Ticker.txt` 中的“北京实时新闻”只是底部滚动的氛围文本，**不触发效果**，不计入 37 条随机事件。

每次移动到另一个地点，游戏按以下顺序结算一次：

1. 刷新商品价格并随机隐藏商品；最后两天全部商品出现。
2. 债务增加 10%，银行存款增加 1%。
3. 逐条判定 18 个市场事件；同一天可能发生多个。
4. 判定健康伤害事件；最多发生一个。
5. 检查是否强制住院、健康危机或死亡。
6. 判定钱财损失事件；最多发生一个。
7. 若开启黑客活动，再判定黑客事件。
8. 若债务超过 100,000 元，触发债务危机。
9. 扣除一天，并检查第 39/40 天提示和结局。

> 源码用 `RandomNum(N) % freq == 0` 判定。下表的“单次判定率”按代码的离散随机范围计算，并非策划权重。市场事件还要求对应商品当天出现；健康与钱财事件按表中顺序判定，前项触发后不再检查后项，所以后排事件的实际发生率会略低。

市场事件补充规则：

- 当天对应商品未出现在黑市时，该事件即使抽中也会跳过。
- 常规日会执行 3 次“隐藏一个随机商品”，但抽取允许重复，所以实际可能显示 5–7 种商品，并不总是注释所说的 5 种。
- 18 条分别判定，没有“发生一条后停止”的限制，因此可能叠加。例如同一天禁书先 ×5、再 ×8。
- 免费物品受房屋容量限制；容量不足时只获得剩余可容纳数量，完全没有空位时会提示“房子太小”。
- 基础价格范围：进口香烟 100–449、走私汽车 15,000–29,999、盗版 VCD/游戏 5–54、假白酒 1,000–3,499、禁书 5,000–13,999、进口玩具 250–849、水货手机 750–1,499、伪劣化妆品 65–244。

健康事件补充规则：

- 按顺序检查，第一条命中后停止，所以每天最多一个直接伤害事件。
- 伤害结算后，若健康低于 85 且剩余时间大于 3 天，会被好心市民送医：
  - 随机住院 1–2 天；
  - 债务增加 `住院天数 × (1,000–9,499)` 元；
  - 健康恢复 10 点，上限 100；
  - 除住院天数外，本次移动本身仍会再消耗 1 天。
- 健康低于 20 且大于 0 时显示“健康危机”提示，但在游戏前期通常会先进入强制住院分支。
- 源码以健康 **小于 0** 判定死亡；健康恰好为 0 不会立即死亡。不过死亡检查排在强制住院之后，因此剩余时间大于 3 天时会先住院，只有没有进入住院分支（通常是最后 3 天）才会执行死亡。死亡文案为：“俺倒在街头，身边日记本上写着：‘北京，我将再来！’”
- 昏迷地点由“当前区域 + 29 个场景”随机拼接，例如发廊、早点摊、公共汽车、厕所、三陪女怀里、民工脚下、电线杆顶端、网络公司尸体旁边等。这些只是住院文案变体，不是独立数值事件。

## 5. 可选黑客事件

只有在设置中开启“黑客活动”才判定；每次移动的触发率为 **4%**。

| 条件 | 结果 |
|---|---|
| 存款 <1,000 元 | 抽中后无事发生 |
| 存款 1,000–100,000 元 | 存款只会增加；增加额为 `存款 ÷ (1–15)`，其中除数为 1 时可直接翻倍 |
| 存款 >100,000 元 | 65% 概率减少、35% 概率增加；变化额为 `存款 ÷ (2–21)` |

文案统一为“黑客入侵银行网络，疯狂修改数据库，我的存款增加/减少了……”。

## 7. 商品交易触发的声望事件

| 操作 | 效果 |
|---|---:|
| 每完成一笔《上海小宝贝》（禁书）卖出交易 | 声望 −7；首次显示“污染社会”提示 |
| 每完成一笔假白酒（剧毒）卖出交易 | 声望 −10；首次显示“危害社会”提示 |

声望按“每次卖出操作”扣除，与卖出数量无关，最低为 0。结算称号为：

| 声望 | 称号 |
|---:|---|
| ≥100 | 德高望重 |
| 90–99 | 杰出青年 |
| 80–89 | 一般般 |
| 60–79 | 不佳 |
| 40–59 | 争议人物 |
| 20–39 | 差 |
| 10–19 | 源码本意似为“很差”，但条件写成 `fame < 20 >= 10`，实际会落入“江湖唾弃” |
| <10 | 江湖唾弃 |

因此原版代码里的“很差”称号实际上不可达。

## 8. 玩家主动触发的设施事件

### 医院

- 健康低于 100 时可购买治疗，每恢复 1 点健康花费 **3,500 元现金**。
- 现金不足则医生拒绝治疗。
- 健康为 100 时访问，会被护士指去神经科。

### 邮局 / 给村长打电话

- 尚有债务：可以用现金还债；输入金额超过现金时遭村长老婆嘲讽。
- 债务清零后，根据 `现金 + 存款` 显示不同反馈：
  - <1,000：被骂“没钱，有神经病”；
  - 1,000–100,000：询问是否支援家乡 1,000 元，但源码并不真正扣款；
  - 100,000–10,000,000：村长想把女儿嫁给玩家；
  - >10,000,000：村长称玩家“简直是我亲爹”；
  - 边界值恰好等于 1,000、100,000 或 10,000,000 时进入“农村年轻人的典范”兜底文案。

### 网吧

- 身上至少要有 15 元现金才能进入，但进入后并不扣 15 元。
- 每次反而获得 1–10 元“美国网络广告费”。
- 一局最多成功进入 3 次；第 4 次起村长要求玩家去做正经买卖。

### 房屋中介

- 初始容量 100，每次成功租房增加 10，最大 140。
- 现金少于 30,000 元时被拒绝。
- 现金恰好 30,000 元时实际扣 25,000 元；高于 30,000 元时实际变为 `现金 ÷2 −2,000`。
- 对话框展示的价格与实际扣款并不完全一致；成功后提示“中介公司骗了我一些钱”。
- 容量到 140 后，再访问会被中介以“房子比局长的还大”拒绝。

### 银行、机场和城区切换

- 银行只负责现金与存款互转，本身没有额外随机事件。
- “机场/网络俱乐部”只是打开信息页面，没有数值变化。
- “我要逛京城 / 我要进地铁”只是切换两套地点名称，不耗天数；真正点击另一个地点才触发每日结算。

## 9. 彩蛋与非数值事件

- 玩家姓名输入“郭祥昊”时，游戏直接提示“本游戏的作者郭祥昊不玩这个游戏”，不进入游戏。
- “老板来了”按钮会用一篇假工作计划遮住游戏；点击拼写检查会建议把“老板”改成“老板娘”。
- 开始游戏前轮播 `Tips.txt` 中的赚钱提示；这些是攻略文本，不会改变状态。
- 底部 `News.txt` 是加密存储的滚动新闻，内容包括假酒、走私汽车、伪劣化妆品、申奥、沙尘暴等讽刺新闻，但没有任何事件回调或数值效果。
