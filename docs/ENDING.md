# 终章：洛杉矶没有第五十三周

## 固定剧情

**WEEK 52 · 最后一天**

**门响了。美国梦醒了。**

你以为还有下周。

第 52 周的一个清晨，敲门声比闹钟先响。你以为是房东，门外却是 ICE 执法人员。对方核对了姓名，没给你收拾生活的时间，就把你直接带走。

锅里还有昨夜的饭，手机上还有没回的报价。车窗外，熟悉的路口一个接一个退后。你突然明白：这座城市照常醒来，只是今天不再需要你。

之后的日子缩成了几道门、几次叫号和一张纸。剩下的货被清算，账户里扣掉 500 美元，换来一张飞往广州的单程机票。在这个故事里，你被永久禁止再次进入美国。

> ONE WAY / 单程 · $500
>
> LAX 洛杉矶 → CAN 广州
>
> 行李：一年的浮生。无返程。

你带走的，究竟是本钱，还是一身还没来得及算的账？

页面固定提供“翻开这一年的账单”和“查看排行榜”，长文可滚动，按钮留在屏幕下方。

## 一年账单

- **回国净本钱**：清算、机票处理后的现金 + 存款 − 未偿债务。
- **这一年净赚**：期末净资产 − 本局实际开局净资产。它是净资产变化，包含利息、事件、奇遇奖励与支出，不是营业流水。
- **累计健康损耗**：每次健康实际下降的点数总和；接受治疗不会冲销历史损耗，因此可超过 100。另列剩余健康、累计恢复点数和诊所支出。
- **走过的街区**：去重后的实际到达地点数，包括起点。
- **经历的事件**：稳定事件 ID 去重后的种类数，另列总遭遇次数；同一地点重复打工或投资算同一种经历。

机票先扣现金，再扣存款；不足部分计入待偿债务，总净资产必定减少 $500。库存先按最近可用行情清算，无报价时按基础价计算，并沿用有效的世界事件交易收入倍率。进入第 52 周时立即结束，不再给玩家一次第 52 周操作，也不触发新的普通随机事件。旅行、原地推进和跨周拘留均使用这一规则；重复打开结局不再次收费。

健康提前归零使用独立的失败故事，不收机票费，不清算库存；榜单明确按现金 + 存款 − 债务排名。旧存档未记录的年度数据展示“未记录”，已经结算的旧成绩不追扣机票。

## 尾声：广州

广州白云机场的门打开，潮湿的热风扑在脸上。手机重新连上网络，家人的消息一条接一条跳出来。你打了很久，最后只发出四个字：『我回来了。』

**净本钱不大于零：行李很轻，日子还重**

算上未还的债，你还没有真正属于自己的本钱。回到广州，第一件事不是开店，而是给债主回电话，把账摊开，再找一份能按时领工资的工作。美国没有替你还清生活，但你终于不用隔着时差面对它。

**净本钱小于 $10,000：先站稳，再出发**

这笔钱能让你喘口气，却经不起再赌一次。你打算先租个小房间，找工作，把每月的开销写下来。第一笔按时到账的工资，也许没有美元那么好看，却能让明天踏实一点。

**净本钱 $10,000 至不足 $50,000：这一次，从一门小生意开始**

你有了一笔可以安排的本钱。你想起在洛杉矶摸熟的进货、议价和记账，决定先找工作，再用小额预算试做生意。先有客人，再谈店面；先留生活费，再谈扩张。你已经知道，流水不是利润，胆子也不能当本金。

**净本钱至少 $50,000：你终于有了选择的余地**

这笔结余让你可以缓一缓，不必在落地当天就答应第一份工作。你列出生活费、备用金和试营业预算，准备从自己懂的买卖做起。这一次，你有资格选择，但你不打算再把全部身家压在一个承诺上。

**健康不足 40 时补充**

只是搬行李时，腰背的疼提醒你：账上的钱不是这一年的全部。先休养，把身体照顾好，生意可以晚一点开始。有正结余时，尾声标题为“本钱有了，身体要慢慢还”。

**其余健康状况补充**

你把行李放下，决定今晚好好吃一顿，睡一觉。明天的事，明天清醒地做。

**共同落幕句**

洛杉矶没有第五十三周。广州，还有明天。

这些阈值用于选择虚构叙事，不包含汇率换算，也不作现实创业成本判断。永久禁入是角色的固定故事设定。

## 排行榜与事件记录

“查看排行榜”打开原生弹出页面：

1. 本机全部 Profile 各显示一条历次最高净资产成绩，按净资产从高到低排列。负成绩照常保留；同分优先较早达成的记录，再以稳定 ID 打破完全相同的排序条件。
2. 点玩家进入其全部已完成旅程，不只保留最好的一局。
3. 点一局进入“这一年的故事”，展示该局成绩与按周排列的完整日记，包括世界事件、地区事件、工作、投资、奇遇、终章及旧存档已有的日记条目。
4. 完成时自动归档；同一局重复存档和打开排行榜不会重复入榜。重开前归档失败则留在当前结局并提示重试。
5. 独立文件 `journey-records-v1.json` 与三个活动存档槽分离。重开或删除存档槽不会抹掉成绩。损坏或读取失败显示错误和重试入口，不假装空榜。

当前没有公共排行榜后端与全球玩家身份系统，因此页面明确写“本机排行榜”。历史档案仅在本机保存，不随现有 iCloud 活动存档同步。全球榜需要另行接入公共服务，不能用本机数据冒充所有在线玩家。
