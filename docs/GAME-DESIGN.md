# 游戏机制设计

## 核心幻想

主角通过跨过边境围栏的方式从墨西哥进入美国，身上只有 2,000 美元现金、一本外国护照，并欠下 5,000 美元。一路辗转后，他来到洛杉矶丁胖子广场，从这里开始为期 52 周的极限生存。

新局进入地图前会显示背景弹窗，交代身份、资金、债务、地点和生存期限。

## 每周循环

每周只能选择一种赚钱方式：

1. **倒卖**：查看本地市场，买卖商品，再前往其他地点完成本周。
2. **打工**：完成当前位置的现金工作，获得稳定工资并损失少量健康。
3. **投资**：投入一笔现金，按照当地项目的风险在本周直接结算盈亏。

行动完成后，周数 +1，债务和存款计息，市场刷新。银行、还债、诊所和仓储属于辅助服务，不占用每周赚钱行动。

一旦本周发生第一笔买入或卖出，本周行动就锁定为倒卖，不能再打工或投资。打工和投资点击确认后直接进入下一周。

## 当前规则

| 参数 | 数值 | 说明 |
|---|---:|---|
| 总时长 | 52 周 | 进入第 52 周立即触发终章 |
| 初始地点 | 丁胖子广场 | 草根华人商圈和低门槛起点 |
| 初始现金 | $2,000 | 可用于进货、还债或投资 |
| 初始债务 | $5,000 | 建立早期生存压力 |
| 随身证件 | 外国护照 | 当前作为背景与日记信息 |
| 债务周利率 | 2% | 不还债时 52 周后约增长至 $14,000 |
| 存款周利率 | 0.2% | 给保守资金一个小收益 |
| 初始容量 | 100 | 商品统一占用一格 |
| 每周商品 | 5 / 10 | 最后一周显示全部商品 |
| 可移动地点 | 15 | 覆盖洛杉矶核心区、圣盖博谷和橙县 |
| 失败条件 | 健康为 0 | 进入第 52 周则遣返、清仓并结算 |

## 倒卖

倒卖保留《北京浮生记》的核心结构：

```text
本周价格 = 基础价 × 地区系数 × 随机波动 × 事件修正
```

玩家需要识别稳定的进货端和出货端，同时承担每多过一周债务继续增长的压力。移动不额外收费，但会完成本周并刷新行情与随机事件。

## 打工

十五个地点各有一份当地工作。界面只显示工作名称、基础工资和健康消耗。基础工资约为 $320–$560，结算时有机会出现小费、加班费、扣款或声望变化。

打工是最稳定的现金来源，但连续打工会消耗健康，也会放弃本周倒卖和投资机会。

## 投资

十五个地点各有一个带当地背景的短期项目，分为低、中、高风险。玩家从几个简单金额中选择投入，盈亏当周结算，不建立长期持仓：

- 低风险：−8% ～ +8%
- 中风险：−20% ～ +25%
- 高风险：−45% ～ +60%

投资结果会生成一条故事记录。首版不加入走势图、组合管理、锁定期或分红系统，后续只需修改项目和结果文案即可扩展内容。

## 事件

现有 56 个洛杉矶本地事件（市场 25、健康 18、钱财 13）用于倒卖旅程；打工和投资各自生成一条与行动相关的简短结果。

此外，游戏加入 6 个独立的世界事件。它们在第 5、12、20、28、36、44 周分别按各自概率判定一次，成功后持续若干周，并同时修正打工、倒卖、存款利息、投资盈亏、债务利息、健康和声望。触发时会立即弹窗，生效期间会常驻显示在市场面板。完整数值见 [世界事件表](WORLD-EVENTS.md)。

本地事件和世界事件的数据与文案均保持数据化，后续可以逐条微调而不修改界面结构。

## 结算

进入第 52 周立即触发 ICE 上门的固定剧情，停止所有经营操作。剩余库存按最近可用报价自动清算（无报价则使用基础价），再扣除 $500 广州单程机票；依次使用现金、银行存款，不足部分记入未偿债务。最终成绩为：

```text
最终净资产 = 现金 + 银行存款 − 剩余债务
```

健康归零则立即失败，不触发遣返、不收取机票费，未清算库存不计入成绩。终局提供剧情、年度账单及本机排行榜；每个 Profile 展示历次最高净资产，点入后可查看全部已完成旅程及按周排列的历史事件。重开与删除存档槽不删除成绩档案。详见 [终局故事与结算](ENDING.md)。

## 暂不加入

- 技能树、装备树和职业等级
- 长期投资组合和股票走势图
- 多阶段任务或复杂身份系统
- 交通费用、房租和固定生活支出

这些内容等首版 52 周循环试玩稳定后再决定是否需要。
