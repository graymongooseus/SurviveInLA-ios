# 游戏机制设计

## 核心幻想

玩家带着少量现金和一笔债务来到洛杉矶，在 40 天内穿梭于不同社区，通过观察区域价格、承担风险和处理生活事件，争取还清债务并留下尽可能多的净资产。

## 每日循环

1. **查看状态**：现金、债务、健康、声望和剩余天数。
2. **查看本地市场**：当前区域出现五种商品及当日报价。
3. **交易**：买卖商品，受现金和背包容量限制。
4. **选择目的地**：地图点选其他区域，显示建议交通方式。
5. **跨天结算**：天数 +1，债务和存款计息；与原版一致，移动本身不扣现金。
6. **生活事件**：获得工作机会、罚单、健康损失或声望变化。
7. **刷新市场**：进入新区域并生成当地价格，回到步骤 1。

这个循环应当控制在 30–60 秒完成一次，让玩家持续面对“现在卖，还是再赌一天”的决定。

## 当前首版规则

| 参数 | 数值 | 说明 |
|---|---:|---|
| 总天数 | 40 | 到期进行最终结算 |
| 初始现金 | $2,000 | 可立即开始交易 |
| 初始债务 | $5,000 | 建立早期压力 |
| 债务日利率 | 10% | 暂时保留经典高压模式 |
| 存款日利率 | 1% | 鼓励资金安全选择 |
| 初始容量 | 100 | 商品目前统一占用一格 |
| 每日商品 | 5 / 10 | 无重复抽取，修复原版随机隐藏问题 |
| 可移动地点 | 10 | 洛杉矶地点使用独立稳定 ID |
| 同日设施 | 银行、债务、诊所、仓储 | 使用设施不推进天数 |
| 失败条件 | 健康为 0 | 第 40 天结束则清算剩余库存并结算 |

10% 日利率经过 39 次结算后，会让未偿还的 $5,000 债务增长到约 $205,000。它能形成经典版的强压力，但很可能不适合作为默认难度。正式平衡建议保留三档：

- 故事模式：2%，事件压力较低。
- 标准模式：3%–4%，作为默认体验。
- 经典模式：10%，保留原版味道。

当前先保留 10%，用于验证风险提示和还债需求是否足够清晰。

## 价格系统

每件商品包含基础价、最低价、最高价。当天价格由以下因素组成：

```text
当日价格 = 基础价 × 区域系数 × 随机波动 × 事件修正
```

当前已经实现基础价、各地点的商品价格倾向和 0.78–1.24 的随机波动。地点倾向负责形成可学习的套利路线，日间波动负责让每次到访仍有不确定性。事件修正和供需记忆放在下一阶段。

设计目标不是预测真实市场，而是制造三个可理解的信号：

- 区域差异：某类商品在哪些社区通常更便宜。
- 日间波动：玩家是否愿意承担多一天的利息风险。
- 新闻事件：给出一次清晰、短暂、可利用的机会。

地点不再使用一个对全部商品生效的统一价格倍率。十个旅行点统一为社区型市场，每处有明确的货源或需求侧定位；“联合车站”一类交通设施不再与社区并列。详见 [地点设计](LOCATIONS.md)。

## 商品和内容方向

当前商品池包括：限量球鞋、二手相机、黑胶唱片、周立波脱口秀、茅台酒、国产零食、游戏主机、美妆套装、二手特斯拉和走私电子烟。

事件内容围绕洛杉矶生活成本与机会：临时工作、停车罚单、热浪、社交媒体曝光、朋友借宿和设备维修。后续可以加入房租、汽油、公共交通、签证/身份压力、影视零工和社区关系，但需要统一决定作品是偏写实、黑色幽默还是轻喜剧。

## 已完成的基础机制

- 银行存取款与主动还债
- 按点治疗和现金结算
- 容量从 100 格逐次升级至 140 格
- 第 40 天最终行情、剩余货物自动卖出和成绩结算
- 健康归零失败、日记与重新开始

## 后续机制优先级

1. SwiftData 自动存档与继续游戏。
2. 逐批替换和扩展洛杉矶事件。
3. 区域专长、交通时间和不同风险等级。
4. 有前兆的市场事件，避免纯随机挫败。
5. 房租与固定生活支出。
6. 成就和每日挑战。

不建议早期加入装备树、技能树或复杂任务系统；它们会稀释交易循环，且难以在玩法尚未平衡时评估价值。
