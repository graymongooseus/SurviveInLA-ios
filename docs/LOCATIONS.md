# 游戏地点设计

## 设计原则

十五个可旅行地点覆盖大洛杉矶华人实际生活圈：洛杉矶核心区、圣盖博谷与橙县。地点可以是社区、商业节点或标志性活动场所，但每处只承担一到两个容易记住的交易角色，让玩家逐渐形成“去哪里进货、去哪里出货”的路线判断。

地图从圣塔莫尼卡向东延伸到罗兰岗与尔湾，向北覆盖帕萨迪纳，向南连接威斯敏斯特·小西贡。较远的地点不只是地图扩张，也承担跨城套利、族裔社区和支线故事的差异。

## 被替换的旧地点

- 时尚区替换为帕萨迪纳·玫瑰碗，引入跳蚤市场、收藏品与大型赛事故事。
- 博伊尔高地替换为菲格罗亚走廊，引入 USC、Exposition Park 与场馆经济。
- 蒙特利公园以更具体、更有华人生活质感的“丁胖子广场”呈现。
- Hacienda Heights 改为尔湾，用于高端华人、科技从业者与资产型支线。
- 唐人街改为威斯敏斯特·小西贡，扩展越南与华裔移民家庭的故事空间。
- 世纪城与西侧高消费定位重复，改为西木区，引入校园客群和游戏主机、国产零食的需求。

旧存档中的地点 ID 会在读取时自动迁移：时尚区归入帕萨迪纳·玫瑰碗；市中心、艺术区、博伊尔高地和联合车站归入菲格罗亚走廊；世纪城归入西木区。

## 开局位置

新局固定从丁胖子广场开始。这里连接主角刚抵达洛杉矶的背景，也是早期低价小商品、现金工和社区投资机会的集中点。

## 数值约定

地点倾向是某一商品基础价的倍率；未列出的商品倍率为 `1.0`。当前每周随机波动为 `0.78–1.24`。地点倾向不是保底差价，玩家仍需要查看本周行情，但长期应能辨认稳定的进货端与出货端。

后续如果加入交通成本、区域事件或设施，优先扩展这十五个地点的差异；继续增加地点前先评估手机地图的可读性。
