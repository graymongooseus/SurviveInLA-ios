# 名人交互事件

## 已确认的设计决定

2026-09-08，用户确认：把贾跃亭投资事件归入一个独立类别，名称为“名人交互事件”。此类别也包含徐静蕾、陈冠希，未来可以继续增加人物和互动故事。

当前状态（2026-09-10）：名人名册与投资、合影、片场三种玩法已接入。吴宇森的 Hollywood 龙套与 10 周后票房分红已实现，详见 [吴宇森片场事件](WU-YU-SEN-HOLLYWOOD-EVENT.md)。贾跃亭投资已迁入新类别；陈冠希的 Santa Monica 合影、三种限时增益和售照已实现。徐静蕾已登记人物，具体互动尚待设计。详见 [陈冠希合影](CHEN-SANTA-MONICA-EVENT.md)。

## 三个概念分别管理

- **事件类别**：名人交互事件，用来组织、查找这类故事。
- **出场人物**：贾跃亭、徐静蕾、陈冠希、吴宇森。同一人物可以出现在多个事件中。
- **交互玩法**：已有投资、合影与片场角色选择；其他玩法需根据故事确定，例如合作邀请或提供协助。名人交互不要求所有人物都邀请投资。

地点、阶段、运气、关系等属于触发条件；加钱、扣健康、获得增益等属于结果。一个名人事件仍然可以限定地点，也可以产生健康或金钱效果。

```text
名人交互事件
├── 贾跃亭
│   └── 罗兰岗夜市的 FF 投资邀请（已有玩法，已归入名人交互）
├── 徐静蕾
│   └── 首次互动剧情待确定
├── 陈冠希
│   └── Santa Monica 合影：摩天轮／沙滩／66 号公路牌
└── 吴宇森
    └── Hollywood 片场：两个龙套角色／群演盒饭，以及上映后分红
```

## 后续互动设计

沿用用户此前的 NPC 方向：人物在不同阶段，根据玩家运气和与该人物的关系，可能提供协助 buff 或带来困扰 debuff。个人限时增益已支持运气、逐回合健康和打工倍率；完整关系系统仍属于后续开发。

每个人的第一段故事先回答：

1. 在什么地点、什么阶段遇见？
2. 他提出什么事情，玩家有哪些选择？
3. 选择后当场发生什么，是否还有后续？
4. 会改变关系、运气、金钱或持续增益中的哪些内容？

目前尚未确定徐静蕾的具体剧情；陈冠希的首个事件已确定并实现。任何后续创作示例都应标为游戏虚构剧情，不作为现实人物行为的事实描述。
