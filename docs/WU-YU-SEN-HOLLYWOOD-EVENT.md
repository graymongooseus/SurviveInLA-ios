# 吴宇森：好莱坞片场邀约

这是为游戏编写的虚构剧情。事件属于“名人交互 · 片场”，与名人投资和合影并列。

## 触发与选择

实际抵达 Hollywood，且抵达结算时的有效运气 **≥55**，必定遇到吴宇森。停留原地过周、刷新界面或读档不会新增邀约。当前默认每局一次；最晚第 42 周触发，保证还有 10 周等到上映。这两个默认规则可分别通过 `oncePerJourney` 和 `requiresTimeForBonus` 调整。

你误入一条临时封闭的侧街，吴宇森正在补拍镜头，原定的小演员却没有赶到。他递来一页通告，让你挑个角色，也可以只站在人群里做背景、收工领盒饭。

| 选择 | 当场片酬 | 健康变化 | 运气变化 | 10 周后的额外分红 |
|---|---:|---:|---:|---:|
| 教堂门口的送信人 | $300 | −5 | 0 | $3,000 |
| 码头追逐戏的倒霉路人 | $600 | −12 | 0 | $6,000 |
| 只做背景群演、领一份盒饭 | $0 | +10 | +3 | 无 |

- 本轮按“先领片酬，10 周后**额外**分得片酬的 10 倍”实现，两个龙套合计收入分别为 $3,300、$6,600。
- 盒饭当场吃掉并恢复健康，不额外创建背包物品；健康和运气仍有 100 的上限。
- 选择不额外消耗一周或占用普通打工次数。健康不足时仍可选龙套，体力消耗可能导致健康归零；选择卡明确显示健康代价。
- 片酬与分红是固定约定金额，不乘普通打工或世界收益倍率。健康变化也按卡片数值执行。
- 邀约文案只展示当场选择，不提前告知电影大卖和分红金额。10 周后才弹出剧组消息。

## 后续如何发生

角色选择后，立即记下当初片酬、分红金额、上映回合和故事文本。玩家离开 Hollywood、原地过周或跳过多周，都由同一回合流水线检查到期。

第 42 周参演，会在第 52 周拿到分红，再进行旅程资产清算。若在到期前健康归零，游戏不能继续推进，自然不会收到尚未到期的分红。分红已入账后关闭弹窗不会再发钱。

邀请、同次抵达队列、已做选择、待发分红和未读结果均保存。v6 快照兼容 v1～v5；原有 FF 投资、陈冠希照片和增益字段保留。

## 文件分工

| 文件 | 用途 |
|---|---|
| Resources/Content/events/celebrities/wu-yu-sen.json | 地点、运气条件、三种角色、片酬和上映参数 |
| Resources/Content/characters/celebrities.json | 吴宇森的人物登记 |
| Resources/Content/localisation/zh-Hans.json | 邀约、角色结果和电影大卖的中文故事 |
| Domain/Events/CelebrityActingModels.swift | 角色、片场邀约和待发分红的数据格式 |
| Engine/Events/CelebrityActingEngine.swift | 抵达触发、角色选择、即时结算和到期分红 |
| Engine/Turns/TurnEngine.swift | 统一调用抵达检查与逐回合分红检查 |
| Store/GamePresentation.swift | 与世界事件、人生选择、投资和合影弹窗依次显示 |
| UI/Home/CelebrityActingOverlay.swift | 三个选项和后续消息的窗口 |
| SurviveInLATests/CelebrityActingTests.swift | 触发边界、收益、十周计时、最终周、存档和重复点击检查 |

这些路径除测试外以 SurviveInLA 为起点。以后增加相同片场玩法，可以新增人物和 JSON 故事，不必在 GameEngine 中增加该人物的判断分支。
