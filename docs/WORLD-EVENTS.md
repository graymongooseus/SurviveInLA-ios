# 世界事件表

世界事件独立于各地区的本地随机事件。游戏进入指定周次时只判定一次；判定成功后立即弹窗，并在持续期内对全局数值生效。当前事件的时间段互不重叠，同一时间最多存在一个世界事件。

## 计算口径

- 打工：当地工资、小费、扣款或菲格罗亚扫黄翻倍结算后，再乘世界事件系数。
- 倒卖：只修正卖出收入和最终清仓收入，不改变买入成本或市场报价。
- 存款与债务：修正每次跨周时的利息，不直接改变本金。
- 投资：修正当周已抽取的正或负盈亏；系数越大，盈利和亏损的绝对值都会更大。
- 健康与声望：修正事件、打工和服务造成的正负变化，最后仍限制在 0～100。
- 所有整数结果采用四舍五入；存款与债务利息沿用向下取整。

事件数据统一保存在 `SurviveInLA/Domain/WorldEvents.swift`。新增或调整世界事件时，只需修改该文件中的周次、概率、持续时间、文案与七项系数。
